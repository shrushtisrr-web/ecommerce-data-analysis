# Amazon E-Commerce Sales Analysis & Dashboard

# Project Overview

This project focuses on analyzing an Amazon e-commerce sales dataset to identify sales patterns, product performance, order trends, fulfilment performance, and geographic sales distribution.

The project follows a complete data analytics workflow using **Excel, Python, and Power BI**, from data cleaning and exploratory analysis to interactive dashboard development.

---

# Project Objectives

- Clean and prepare raw e-commerce sales data
- Perform data quality checks and exploratory data analysis
- Analyze sales and quantity by product category
- Understand order status and fulfilment performance
- Identify top-performing states and cities
- Analyze monthly sales trends
- Build an interactive Power BI dashboard
- Generate meaningful business insights from the data

---

# Dataset

The dataset contains Amazon e-commerce order information, including:

- Order ID
- Date
- Order Status
- Fulfilment
- Sales Channel
- Product Category
- SKU
- Size
- Quantity
- Amount
- Shipping Location
- Promotion Information
- B2B Information

The dataset contains approximately 129,000 records

---

 Data Cleaning

Data preparation was performed primarily using Excel and Python.

Key steps included:

- Checked for missing values
- Checked for duplicate records
- Converted date values into a usable date format
- Handled missing promotion information
- Identified missing sales amounts
- Created a data quality flag for cancelled orders without sales amounts
- Examined zero-quantity records
- Verified data types and numerical columns

---

 Exploratory Data Analysis

The analysis focused on several business questions:

 Product Analysis
- Which categories generate the highest sales?
- Which categories have the highest quantity sold?
- How concentrated are sales across categories?

Order Analysis
- What is the distribution of order statuses?
- How many orders were cancelled?
- How does fulfilment affect sales?

 Geographic Analysis
- Which states generate the highest sales?
- Which cities contribute the most to sales?

 Time Analysis
- How do sales change over time?
- Which months show higher or lower sales activity?

---

 📈 Key Findings

Some of the major findings from the analysis include:

- **Set** was the highest-selling category.
- **Kurta** was the second-highest-selling category.
- Sales were concentrated among a few major product categories.
- **Amazon fulfilment** generated more sales than merchant fulfilment.
- Shipped orders represented the largest portion of order statuses.
- A significant number of cancelled orders had zero quantity.
- Sales were geographically concentrated across particular states and cities.
- Monthly analysis showed variations in sales throughout the period.
